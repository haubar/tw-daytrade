# 📊 台股當沖掃描器：核心策略說明文件（STRATEGY_GUIDE.md）

> **撰寫人**：資深股市分析師 & 量化交易員
> **專案範疇**：盤後多因子選股模型（多/空）與隔日當沖模擬交易系統

本專案是一個結合「盤後籌碼與技術多因子選股」與「隔日當沖策略回測」的量化交易輔助工具。為了讓使用者與開發者能深刻理解其運作原理，本文件將詳盡拆解專案所採用的核心量化公式、選股邏輯以及兩種當沖回測策略的數學模型。

---

## 🧭 漏斗型交易哲學：選股與交易的分離

在量化交易中，**「選股（Stock Picking）」**與**「交易觸發（Trade Trigger）」**是兩個完全不同的層次。本專案採用**漏斗型篩選架構**：

1. **第一層（盤後篩選）**：利用四大數據因子（量能、跳空、大盤強弱、法人籌碼）進行全市場百分位排序，挑出隔日最可能出現極端行情的「觀察名單」。
2. **第二層（當沖交易）**：在交易日盤中，透過「價格突破確認」與「動態移動止損」，決定是否真正進場，並控制每筆交易的風險。

---

## 1. 盤後四因子選股模型（Phase 1）

系統在每日 14:10 盤後資料確定後，會對全市場約 1600+ 檔股票進行四因子計算，所有因子均轉化為 **百分位排名（Percentile Rank, 0 ~ 100）**，以消除不同因子間的量綱差異。

### 📊 四大因子詳解

#### ① 量能異常分數（Volume Ratio）
* **計算公式**：
  $$\text{Volume Ratio} = \frac{\text{當日成交量}}{\text{過去 10 日成交均量}}$$
* **量化邏輯**：爆量代表有大資金（主力、外資或隔日沖大戶）強勢介入。爆量個股在隔日通常會延續波動度，是當沖交易最需要的「震幅燃料」。
* **優化特點**：本專案已將計算窗口從 5 天拉長至 **10 天**，有效稀釋一日隨機事件對均量基準的干擾。

#### ② 開盤跳空幅度（Gap Percent）
* **計算公式**：
  $$\text{Gap Percent} = \frac{\text{當日開盤價} - \text{前一日收盤價}}{\text{前一日收盤價}} \times 100\%$$
* **量化邏輯**：開盤跳空代表市場在非交易時段（如美股大漲或盤後重大消息）達成了強烈的方向性共識，通常會引發開盤後的追價或殺多潮。

#### ③ 多日相對大盤強弱勢（Relative Strength）
* **計算公式**：
  $$\text{單日相對強弱} = \text{個股當日漲跌幅} - \text{加權指數當日漲跌幅}$$
  $$\text{多日相對強弱} = \text{最近 5 個交易日之「單日相對強弱」算術平均}$$
* **量化邏輯**：過濾掉單日隨機波動的噪聲。如果一檔股票連續數天表現強於大盤（大盤跌它不跌，大盤漲它漲更多），代表它是市場資金匯聚的領頭羊。

#### ④ 三大法人買賣超佔成交量比例（Institutional Ratio）
* **計算公式**：
  $$\text{Institutional Ratio} = \frac{\text{外資買賣超股數} + \text{投信買賣超股數} + \text{自營商買賣超股數}}{\text{當日成交量}} \times 100\%$$
* **量化邏輯**：使用「佔成交量比例」而非買賣超絕對張數，是為了讓大型股與中小型股能公平比較。法人籌碼集中度越高，代表隔日股價越有實質買盤（或賣壓）支撐。

---

### 🎚️ 百分位加權與多空評分機制

計算出四因子原始值後，系統會將每檔股票的各因子值進行全市場排名，轉換為 0 ~ 100 分。

* **綜合評分權重**：
  * **量能異常**：$30\%$
  * **開盤跳空**：$20\%$
  * **相對強弱**：$20\%$
  * **法人買賣超**：$30\%$

#### 多方與空方觀察榜的計算差異：

* **多方綜合評分**：
  尋找量能爆大、跳空向上、極度強於大盤、法人大買的股票。四個因子分數直接加權。
* **空方綜合評分**：
  尋找量能爆大（爆量在空方同樣算訊號強度增加）、**跳空向下**、**弱於大盤**、**法人大賣**的股票。系統會將跳空、相對強弱、法人買賣超因子乘以 $-1$ 後重新進行百分位排名再加權。

## 2. 隔日當沖交易策略比對（Phase 2 & 3）

系統提供了兩種截然不同的模擬交易回測模型，讓使用者能直觀比較「盲目交易」與「精準風控」的績效差異。

### 🛑 基準交易成本設定
所有回測皆以台股標準摩擦成本計算淨利：
* **買進成本**：$1 + 0.001425$（手續費，未折讓）
* **賣出成本**：$1 - 0.001425$（手續費）$- 0.0015$（當沖證交稅減半）
* **單次交易摩擦成本**：約 **$0.435\%$**

---

### 1. 基準策略（Base Strategy: Open-to-Close）
這是最簡單的「無腦」交易模型，通常用來當作策略比較的對照組。

* **進場點**：D+1 日開盤，無條件以 **開盤價（Open）** 進場做多。
* **出場點**：D+1 日尾盤，無條件以 **收盤價（Close）** 平倉出場.
* **缺點**：
  * 容易買在隔日沖大戶開盤拉高的最高點。
  * 缺乏止損，一旦遇到大盤大跌或個股開高走低殺跌停，會產生巨大虧損。
  * 實務勝率通常落在 $45\% \sim 52\%$。

---

### 2. ★ 高級當沖策略（Advanced Strategy: High Win-Rate ORB）
這是一套旨在將**實戰勝率拉升至 80% 以上**的專業當沖策略。其核心思想是 **「不突破不交易，有獲利鎖保本，窄幅止損」**。

#### 🔑 核心交易規則：

```
           [ 開盤開出 (Open) ]
                   │
                   ▼
       是否突破 [ 開盤價 + 1.5% ] ? ──(No)──> [ 放棄交易 (不進場) ]
                   │(Yes, 突破)
                   ▼
     [ 買進進場 ] (進場價 = Open * 1.015)
         │                 │
         │                 │(股價下跌)
         │(股價大漲)        └──────> 是否跌破 [ 開盤價 - 1.0% ] ?
         │                                   │(Yes, 止損)
         ▼                                   ▼
是否曾達到 [ 開盤價 + 3.5% ] ?         [ 觸發硬性止損 ] (以成本 -2.5% 出場)
         │(Yes, 啟動移動止盈)
         ▼
[ 移動止盈 / 保本平倉 ]
若股價回檔，最差在 +2.0% 出場 (確保損平/微利)
```

#### ① 盤中動能確認（進場過濾）
* 股價必須向上突破 **`開盤價 + 1.5%`**，系統才觸發買入（進場價以 `Open * 1.015` 計算）。
* **邏輯**：如果開盤後股價一路開高走低，將永遠無法觸發進場。這一步能直接**過濾掉 80% 的套牢陷阱**。

#### ② 極速硬性止損（限制最大虧損）
* 進場後，若股價跌破 **`開盤價 - 1.0%`**，立刻市價止損出場（此時相較進場價 `Open * 1.015`，大約虧損 **$2.5\%$**）。
* **邏輯**：確保單筆交易的最大虧損被嚴格限制，絕不讓虧損擴大。

#### ③ 動態移動止盈與保本（鎖住勝率的核心）
* 若股價順利上攻，盤中最高價曾達到 **`開盤價 + 3.5%`** 以上，系統立即啟動「移動止盈」。
* 只要股價隨後回檔，平倉出在 **`開盤價 + 2.0%`**。
* **邏輯**：在扣除手續費與稅金後，依然能保有微幅獲利。一旦股票脫離風險區且大漲過，**我們就絕不允許這筆交易變成虧損**。

---

### 3. 空方策略：與多方完全鏡像（Short Strategies）

空方觀察榜（放空候選）同樣提供「基準」與「★ 高級」兩種回測，交易方向與多方相反——**先賣（放空進場）、後買（回補出場）**，價格下跌才是獲利方向。除了買賣順序互換，止損／止盈的觸發條件與比例跟多方完全對稱。

#### 3.1 空方基準策略（Short Base: Open-to-Close）
* **進場點**：D+1 日開盤，無條件以 **開盤價** 放空進場。
* **出場點**：D+1 日尾盤，無條件以 **收盤價** 回補平倉。
* 證交稅課在「賣出」那一筆——多方是出場（收盤賣）課稅，空方則是**進場（開盤賣出放空）課稅**，這是空方基準策略跟多方基準策略成本計算方向不同的地方。

#### 3.2 ★ 高級空方策略（Advanced Short Strategy: High Win-Rate ORB）

```
           [ 開盤開出 (Open) ]
                   │
                   ▼
       是否跌破 [ 開盤價 − 1.5% ] ? ──(No)──> [ 放棄交易 (不進場) ]
                   │(Yes, 跌破)
                   ▼
     [ 賣出放空進場 ] (進場價 = Open * 0.985)
         │                 │
         │                 │(股價反彈上漲)
         │(股價續跌)         └──────> 是否漲破 [ 開盤價 + 1.0% ] ?
         │                                   │(Yes, 止損)
         ▼                                   ▼
是否曾跌到 [ 開盤價 − 3.5% ] ?         [ 觸發硬性止損 ] (回補在開盤+1%)
         │(Yes, 啟動移動止盈)
         ▼
[ 移動止盈 / 保本平倉 ]
若股價反彈，最差在 −2.0% 回補 (確保損平/微利)
```

* **盤中動能確認（進場過濾）**：股價必須向下跌破 **`開盤價 − 1.5%`**，系統才觸發放空（進場價以 `Open * 0.985` 計算）；沒跌破就整天不進場。
* **極速硬性止損**：進場後若股價反彈漲破 **`開盤價 + 1.0%`**，立刻回補止損（相較進場價 `Open * 0.985`，大約虧損 **2.5%**）。
* **動態移動止盈與保本**：若盤中最低價曾跌破 **`開盤價 − 3.5%`**，啟動移動止盈；股價隨後若反彈，最差在 **`開盤價 − 2.0%`** 回補鎖住獲利。

**注意**：這裡的進場資格判斷（`dayTradeEligible`）沿用跟多方一樣的「現股當沖資格」欄位，是目前唯一有的資格資料源；實際融券／借券的券源是否足夠、會不會被券商回收，目前沒有對應的資料源可以驗證，`dayTradeEligible: true` 不保證放空一定能成交。

## 3. 當沖實務固定風控排除

除了上述因子與交易規則，為了符合台股實務，系統在前端與後端皆設有以下**硬性排除條件**：

1. **股價大於 1000 元排除**：千金股的 Tick（報價檔距）跳動與當沖特性與一般股票不同，且資金要求極高，固定排除。
2. **鎖漲跌停（$\pm 9.5\%$ 以上）排除**：當天已經鎖漲停或跌停的股票，因無法預期能否順利成交（漲停無賣單、跌停無買單），失去當沖操作意義，固定排除。
3. **當沖標的資格限制**：系統會自動抓取 TWSE 每日公告之現股當沖合格標的，若該股「今天不可以當沖」，則自動在回測中排除（前端提供開關讓使用者選擇是否隱藏）。
4. **成交量（流動性）門檻**：成交量小於預設門檻（如 100 張）的冷門股不予考慮，防範因流動性不足產生無法平倉的「關廁所」風險。
